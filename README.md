# PM2.5
MakeCode micro:bit extension for DFRobot SEN0460 via I2C (default 0x19).

Blocks are under **PM2.5** (cloud icon). Namespace `custom` and function names preserve the older project's JavaScript call style.

Import the GitHub repository URL via MakeCode > Extensions after uploading these files to a GitHub repository.

`test.ts` is an example using `serial write value` and should not be added to the normal `files` array.

Hardware not tested. Sensor needs suitable power and a common GND. Confirm the I2C address and the actual sensor power requirements.
